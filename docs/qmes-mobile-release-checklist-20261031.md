## 자동 검사와 수동 검증의 구분
- GitHub Actions `mobile-static`: 모바일 HTML 구문 및 필수 요소 확인. **실제 업무 검증 아님.**
- GitHub Actions `mobile-browser`: 격리된 모의 PC 화면을 사용한 메뉴 이동·터치 크기·320/390px 레이아웃 확인. **운영 로그인, Supabase 연결, 실제 저장/조회 검증 아님.**
- PR 자동 검사가 모두 통과하더라도 아래 실제 기기·실제 QMES 업무 검증 항목은 자동으로 체크하지 않음.
- **실제 검증 전에는 기본 모바일 경로 변경·PR 병합·Render 운영 배포 금지.**
