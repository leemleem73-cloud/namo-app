# QMES 모바일·PC 통합 시험 계획 (2026-10-31)

## 안전 원칙
- main, public/index.html, public/mobile.html, 서버 데이터 변경 금지 (검증 전).
- `public/mobile-unified-preview-20261031.html`은 **별도 시험 페이지**이며 자동으로 기존 모바일을 대체하지 않음.
- 기존 PC 메뉴, 로그인, 전자결재 권한, 저장 데이터는 공통 사용을 목표로 함.

## 검증 절차
1. 시험 브랜치 배포가 가능한 별도 Render 서비스 또는 미리보기 환경에 배포.
2. 모바일에서 `/mobile-unified-preview-20261031.html` 접속 후 로그인 및 새로고침 확인.
3. 작업지시서, IQC, PQC, OQC, LOT 추적, 재고관리, 생산실적, 설비관리, 전자결재, 관리자 권한을 각각 확인.
4. 목록/상세/등록/수정/취소/조회/검색/표 좌우 스크롤 및 모바일 터치 확인.
5. PC에서 동일 문서를 조회해 데이터 동기화 확인. 실제 운영 데이터 대신 테스트 기록 사용.
6. 로그인 실패, 권한 없음, iframe 제한, 캐시, 페이지 새로고침 시 상태 복원 확인.
7. 실패 시 기존 `/mobile.html` 사용. 운영 경로 변경은 별도 검토 및 승인 후 진행.

## 미해결
- 현재 PC 메인 `public/index.html`은 모바일에서 `/mobile.html`로 리다이렉트함. 시험 페이지는 `/?desktop=1&pc=1`을 이용하여 이를 회피.
- iframe 내 PC 앱의 내비게이션/인쇄/다운로드/인증 동작은 실기기 검증 필요.
- CSS/JS 반응형 개선이 모든 개별 업무 화면을 해결한다는 보장은 없음.
- TEST 서버 배포 및 기능 검증 전까지 완료 표시 금지.
