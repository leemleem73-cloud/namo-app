# NAMO QMES 모바일 반응형 릴리스 검증표

상태: 미검증 / 운영 배포 금지. 이 문서는 테스트 절차이며 테스트 성공 증빙이 아닙니다.

## 배포 전 안전 조건
- [ ] PC 메인 대시보드 및 기존 화면의 시각적 회귀 테스트 완료
- [ ] 모바일 뷰포트 360/390/412/768px 확인
- [ ] 로그인/로그아웃, 세션 만료, 새로고침 정상 확인
- [ ] 모바일 메뉴 펼침/닫힘, 하위 메뉴 선택, 뒤로 가기 확인
- [ ] IQC/PQC/OQC 조회, 목록 이동, 상세 조회 확인
- [ ] 작업지시서 목록, 상세 조회, 검색, 수정/등록 UI 확인
- [ ] LOT 추적(원료→완제품 및 역방향) 조회 확인
- [ ] 재고 및 전자결재 조회 화면 확인
- [ ] 인쇄 미리보기 및 출력 레이아웃 확인
- [ ] PC/모바일 권한(작성자, 검토, 승인) 동일성 확인

## 변경 데이터 주의
운영 데이터에 등록/수정/삭제/결재 테스트를 하지 않는다.
쓰기 기능 테스트는 별도 테스트 DB와 명시적인 테스트 계정/데이터에서만 수행한다.
- [ ] 테스트 DB에서 작업지시서 등록/수정/취소 검증
- [ ] 테스트 DB에서 IQC/PQC/OQC 저장 및 판정 검증
- [ ] 테스트 DB에서 전자결재 승인/반려 권한 검증

## 점검 방법
1. 개발 브랜치를 격리된 미리보기 환경에 배포한다(운영 main과 분리).
2. 모바일 브라우저에서 `/mobile-unified-preview-20261031.html?qa=1` 접속.
3. 진단 패널 상태와 실제 화면 캡처를 함께 기록한다.
4. 실제 클릭·조회·저장 결과를 별도로 기록한다. `ui-ready`는 기능 정상의 증거가 아니다.
5. 문제 없을 때만 PR #480 리뷰 후 main 병합한다.

## 롤백
PR #480 병합 전에는 main 영향 없음. 병합 후 문제가 있으면 병합 커밋을 되돌리고 Render 배포 상태를 확인한다.
