# NAMO QMES 모바일 반응형 검증표 (PR #480)

상태: **미검증 / 운영 배포 금지**. 이 문서는 검증 계획이며 합격 증빙이 아닙니다.

## 테스트 환경
- 모바일: Android Chrome, 360/390/412px 화면 폭, 세로 및 가로 방향
- PC: Chrome 1280px 이상 (회귀 확인)
- 테스트 대상: PR #480 브랜치를 배포한 별도 검증 환경
- 로그인: 테스트 계정만 사용, 실제 생산/검사 데이터 변경 금지
- 검증 자료: 화면 캡처, 브라우저 콘솔 오류, 요청/응답 상태, 실행 시각 기록

## 진단
모바일 프리뷰에서 개발자 도구의 `qmesMobileDiagnostics()`는 **읽기 전용 DOM 상태**를 반환합니다.
진단값은 UI 기능 성공 또는 서버 저장 성공을 증명하지 않습니다.

## 배포 승인 조건
1. M01~M15 검증 결과와 캡처 확보.
2. 저장 기능은 테스트 전용 데이터로만 검증.
3. PC 회귀 이상 없음 확인.
4. 문제 시 PR 병합 중단. 운영 DB/기존 PC 코드 덮어쓰기 금지.
