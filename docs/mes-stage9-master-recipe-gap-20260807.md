# MES Stage 9 - 다음 필수 기능 점검

기준일: 2026-08-07

## 현재 완료로 보는 영역
- IQC 합격 입고 -> 원재료 재고
- 작업지시 실투입 -> 원재료 차감
- LOT별 원재료 잔량/홀드/가용재고
- 생산완료 -> 완제품 재고
- 출하 -> 완제품 차감
- 출하 중복차감 방지
- LOT 수불 자동검증 및 최종 검증 화면

## 다음 우선순위
### 1. 품목/원료 마스터
재고, 작업지시, 검사에서 사용하는 품목 정보를 하나의 기준 데이터로 관리한다.

필수 필드:
- 품목코드
- 품명
- 구분: 원재료 / 반제품 / 완제품
- 기본단위
- 사용여부
- 안전재고
- 기본 공급처(선택)
- 비고

### 2. 배합/레시피 마스터
나모케미칼의 단순 생산 특성을 고려해 복잡한 공정 라우팅 대신 제품별 원료 구성과 기준 투입량만 관리한다.

필수 필드:
- 완제품 코드/품명
- 레시피 버전
- 기준 생산량
- 원료코드/원료명
- 기준 투입량 또는 배합비
- 단위
- 사용여부
- 시행일

### 3. 작업지시 연계
작업지시에서 제품과 생산량을 선택하면 승인된 최신 레시피를 기준으로 원료 계획량을 자동 계산한다.

계산식:
원료 계획량 = 작업지시 생산계획량 x (레시피 원료 기준량 / 레시피 기준 생산량)

### 4. LOT 추적 연계
작업지시 실투입 LOT와 레시피 원료를 연결하여 제품 LOT에서 사용 원료 LOT를 역추적하고, 원료 LOT에서 생산된 제품 LOT를 정추적한다.

## 불필요한 확장
현재 규모에서는 다음 기능은 우선 제외한다.
- 복잡한 다단계 BOM
- 공정별 세부 라우팅 엔진
- APS 자동 생산스케줄링
- MRP 전체 기능
- 원가회계/표준원가 엔진
- 창고 로케이션/WMS 고도화

## Stage 9 개발 순서
1. 기존 DB의 품목/재고/작업지시 데이터 구조 확인
2. 기존 데이터에서 품목 마스터 자동 생성
3. 레시피 마스터 저장 구조 추가
4. 작업지시 원료 계획량 자동계산 연결
5. LOT 추적과 레시피 일치 검증 추가

이 단계에서는 기존 운영 데이터를 덮어쓰지 않고 별도 브랜치에서 구현 후 검증한다.
